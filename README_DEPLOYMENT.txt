DEPLOYMENT
1. Upload every file and folder in this package to the public root of your website.
2. Preserve the folder structure: css, js, images and assets.
3. Ensure the hosting account serves index.html as the default document.
4. On Apache hosting, keep the included .htaccess file.
5. Open the site once, then hard-refresh the browser if an older cached design appears.

MAIN FILES
- index.html                 Main portfolio
- css/style.css              Main visual system
- js/script.js               Interactions and animations
- css/auxiliary.css          Privacy, site map and error-page styling
- assets/certificate.pdf     Existing certificate
- site.webmanifest / sw.js   Installability and offline support

SAFE PACKAGING
The uploaded source contained a local FTP configuration with a password and Git history.
These private development files are intentionally excluded from this deployment package.
For security, rotate the old FTP password before using that hosting account again.
